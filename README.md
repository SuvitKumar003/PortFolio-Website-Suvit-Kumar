# Suvit Kumar — Portfolio

A single-page portfolio with no build step. It uses plain HTML, CSS and JS in `index.html`, plus `Suvit_Kumar_Resume.pdf`.

## Deploy for free (pick one)

### Option A: Netlify Drop (about 1 minute, no Git needed)
1. Go to https://app.netlify.com/drop
2. Drag this whole `suvit-portfolio` folder onto the page.
3. You get a live URL. Under **Site settings → Change site name** you can rename it to something like `suvitkumar.netlify.app`.

### Option B: GitHub Pages (URL: `suvitkumar003.github.io`)
1. Create a public repo on GitHub named exactly **`SuvitKumar003.github.io`**.
2. Upload `index.html` and `Suvit_Kumar_Resume.pdf` to it (use "Add file → Upload files").
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. The site goes live at `https://suvitkumar003.github.io` within a minute or two.

### Option C: Vercel
1. Push this folder to a GitHub repo.
2. Go to https://vercel.com/new, import the repo and click Deploy. There's no framework and no build command.

## Updating
- **Resume:** replace `Suvit_Kumar_Resume.pdf` with a new file of the same name.
- **Text and numbers:** edit the `impact`, `jobs`, `skills` and `projects` arrays near the bottom of `index.html`.
